# Liar's Road

## タイトル

ライアーズロード

## 使用技術

* C++
* DXライブラリ
* Visual Studio

## 制作形態

個人制作

## ゲーム概要

「しょぼんのアクション」に影響を受けて制作した、初見殺しギミックを中心とした2Dアクションゲームです。

近づくと急に動くトゲ、踏むと落下する床、穴の近くに配置された隠しブロックなど、初見では回避が難しいギミックを多数実装しました。プレイヤーを驚かせながらも攻略の達成感を得られるようなステージ構成を目指して制作しました。

## 操作方法

【キーボード】

* 左右キー / A,Dキー：移動
* 上キー / Wキー / Zキー：ジャンプ

## 工夫した点

本作品で最も工夫した点は、「自作ゲームならではのオリジナルギミックの実装」です。

単に既存作品の初見殺し要素を模倣するのではなく、独自性のあるトラップの制作を重視しました。

実装したギミックの例：

* 急加速してプレイヤーを追いかけるブロック
* アイテムブロックに見せかけた即死トラップ
* 斜め方向へ移動するトラップ

また、プレイヤーの視界外からトラップが動き出す演出や、自然に危険な場所へ誘導するステージ構成を取り入れ、予想外の展開を楽しめるよう工夫しました。

## 制作を通して学んだこと

本作品の制作を通して、ゲームの企画・設計・実装・デバッグを一貫して行う経験を得ました。また、多数のギミックを実装する中で、クラス分割や処理の整理など、保守性を意識したプログラミングの重要性を学びました。
